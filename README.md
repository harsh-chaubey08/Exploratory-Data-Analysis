# Exploratory-Data-Analysis
Exploratory Data Analysis projects showcasing data cleaning, statistical analysis, and visualization skills using Pandas, Matplotlib, and Seaborn.

---

## 📌 Objectives

* Understand dataset structure and features
* Handle missing values & duplicates
* Perform statistical analysis
* Discover patterns, trends, and correlations
* Create meaningful visualizations

---

## 🛠️ Tech Stack

**Languages**

* Python

**Data Science**

* Pandas
* NumPy

**Visualization**

* Matplotlib
* Seaborn
* Plotly

**Tools**

* Jupyter Notebook
* Git & GitHub

---

## 📂 Project Structure

* `datasets/` → Raw data files
* `notebooks/` → EDA notebooks

---

## 📈 Key Steps in EDA

1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Outlier Detection
5. Univariate Analysis
6. Bivariate / Multivariate Analysis
7. Correlation Heatmaps
8. Insights & Conclusions

---

## 🚀 How to Run

```bash
git clone https://github.com/harsh-chaubey08/Exploratory-Data-Analysis.git
cd Exploratory-Data-Analysis
jupyter notebook
```
